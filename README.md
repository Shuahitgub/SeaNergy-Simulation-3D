# SeaNergy Lamp — Interactive 3D Model

An interactive 3D model and simulation of **SeaNergy**, a seawater electrochemical energy-powered LED lamp prototype.

**Open the live model:** the `index.html` page of this repository (published with GitHub Pages).

## What it shows
- 8 zinc–copper (Zn–Cu) seawater cells wired in series
- Rocker switch, 3–4 V LED and a 126 × 48.5 × 33.5 mm aluminium reflector cup
- Clear tapered lampshade with a honeycomb reflective tape ring under the lid
- Simulation panel: cell voltage, LED voltage, current, power and light output
- X-ray, exploded, tape and cell-layout views; tap any part to learn what it does

## Files
| File | What it is |
|---|---|
| `index.html` | The interactive 3D model and simulation (works offline in Chrome or Edge) |
| `SeaNergy_Lamp.glb` | Coloured 3D model at real size, for 3D viewers and other apps |
| `SeaNergy_Lamp.blend` | Blender scene with lights, floor and camera ready to render |

Dimensions are approximate. The simulation is a teaching model; its default values are illustrative, not measured SeaNergy results.
